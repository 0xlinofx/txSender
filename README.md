Download it with:
```bash
wget https://raw.githubusercontent.com/0xlinofx/txSender/main/txSender.js -O txSender.js
```
or

```bash
curl https://raw.githubusercontent.com/0xlinofx/txSender/main/txSender.js -o txSender.js
```
Then run it:
```bash
node txSender.js
```
Ensure dependencies (ethers, prompt-sync, node-schedule) are installed:
```bash
npm install ethers prompt-sync node-schedule
```
clone the repo, run npm install, and npm start.
